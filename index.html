จัดการแบบฟอร์มเช็คชีท (Check Sheet Templates)

สร้างแบบฟอร์มเช็คชีท กำหนดจุดตรวจ เกณฑ์มาตรฐาน และเงื่อนไขบังคับถ่ายรูป / บังคับระบุค่า

จัดการเครื่องจักรและพิมพ์สติ๊กเกอร์ QR Code

จัดการรายชื่อเครื่องจักร 30 เครื่อง ผูกเช็คชีทประจำเครื่อง และพิมพ์ป้าย QR Code

รหัสเครื่อง ชื่อเครื่องจักร สายการผลิต สเตชั่น (Station) แบบฟอร์มเช็คชีทประจำเครื่อง QR Code จัดการ

การเชื่อมต่อ Google Sheets & ตั้งค่าระบบ

ตั้งค่า URL ของ Google Apps Script (Web App) และรหัส PIN ของหัวหน้างาน

ระบบจะดึงข้อมูลจริงจาก Google Sheets โดยอัตโนมัติเมื่อเปิดแอปพลิเคชัน

ใช้สำหรับล็อกอินเข้าดูหน้าแดชบอร์ด, เช็คชีท, ปฏิทินวางแผน, และจัดการข้อมูลหลัก (ค่าเริ่มต้น: 1234)

สแกน QR Code หน้าเครื่องจักร

ส่องกล้องไปที่แผ่น QR Code ที่ติดหน้าเครื่อง หรือใช้ปุ่มถ่ายภาพเพื่อโหลดเช็คชีททันที
